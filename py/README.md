# ag-ui-validate (Python)

This name is reserved on PyPI for a native Python port of
[ag-ui-validate](https://github.com/langport-dev/ag-ui-validate), a conformance validator
for the [AG-UI protocol](https://docs.ag-ui.com). No functionality ships in this
placeholder release — the TypeScript implementation is the working one today.

See [docs/PYTHON-PORT-PLAN.md](https://github.com/langport-dev/ag-ui-validate/blob/main/docs/PYTHON-PORT-PLAN.md)
in the repository for the port plan, including timing (it starts once the rule catalog
has stabilized against real captured streams).
